# 🛒 E-Commerce Sales Dashboard - Python Project

## 📊 Project Overview
This project analyzes messy e-commerce sales data and creates a full 4-in-1 dashboard. It finds top-selling products and best cities by revenue.

## 🔧 Data Cleaning Done
- Fixed city names (multan -> Multan)
- Removed extra spaces from products (laptop  -> Laptop)
- Handled missing Sales values with Median
- No Numpy used - Only Pandas & Matplotlib

## 📈 Dashboard Includes
1. Sales by Product (Bar Chart)
2. Sales by City (Bar Chart) 
3. Product Share % (Pie Chart)
4. Quantity Sold (Bar Chart)

## 💻 Technologies
- Python
- Pandas
- Matplotlib
